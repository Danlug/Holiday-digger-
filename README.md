# Раскопки на каникулах — веб-сборка

Ветка существует только ради GitHub Pages: здесь лежит готовая сборка,
а не исходный код. Исходники — в `main` и в рабочей ветке.

Пересобрать: `godot --headless --path . --export-release "Web" build/web/index.html`
и скопировать содержимое `build/web/` сюда.

`.nojekyll` обязателен: без него Pages прячет файлы, начинающиеся с точки,
и ломает раздачу.
