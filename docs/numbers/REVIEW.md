# Числа на утверждение: разбор

Все значения с пометкой `"proposed": true` — их придумали агенты, владелец их ещё не утверждал. Здесь они собраны по темам: что это, сколько сейчас, чем обернётся в игре и что советую. **Числа в игре этот разбор не меняет.**

- Всего чисел: **636** в 42 семействах; подозрительных мест: 4; новых без разбора: 0.
- Полная выгрузка (каждая строка со стабильным id `файл:путь`, заметкой агента и расчётом): `docs/numbers/proposed.json`.
- Обновить после любого слияния: `python3 tools/proposed_numbers.py` (без Godot — `--no-sims`). ГДД §18 «Числа».
- Откуда расчёты: симуляторы sim_economy.gd (серпантин, дайв, без артефактов; 4 сида) и sim_daily.gd — запущены сейчас; итоги ботов: 10 прогонов, 111 игровых часов, сборка 20261024-1824 (docs/numbers/bot_anchors.json); tools/sim_tech.py — доход и окупаемость по глубине.
- Как ответить: «оставить» / новое число по id или по названию семейства — агент правит данные и снимает пометку.
